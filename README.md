## Setup guide (one time, about 10 minutes)

1. **Create the repository.** Sign in to GitHub, click **+ → New repository**, and name it exactly `YOUR-USERNAME.github.io` (use your GitHub username). Set it to **Public** and click **Create repository**.
2. **Upload the files.** On the new repo page, click **uploading an existing file**. Unzip this package and drag in everything inside the `portfolio` folder (`index.html`, `_config.yml`, `README.md`, and the `projects`, `documents` and `assets` folders). Click **Commit changes**.
3. **Turn on Pages.** Go to **Settings → Pages**. Under *Source*, choose **Deploy from a branch**, then pick `main` and `/ (root)`. Click **Save**.
4. **Open your site.** Wait 1–2 minutes, then go to `https://YOUR-USERNAME.github.io`.

## Filling it in

Search each file for **`[EDIT`**. Those are the only spots that still need your input (mostly the case study details).

| What | Where |
|---|---|
| Resume PDF | Already included. To update it, upload a new `documents/Tomeeka-Sibley-Resume.pdf` |
| New credential | Copy one `<div class="cred">` line in `index.html` and change the name and Verify link |
| Case study details | Each file in `projects/` follows the same 5 parts: problem, approach, deliverables, result, what it shows |

To edit on GitHub: open the file, click the ✏️ pencil icon, make changes, then **Commit changes**. The site updates within a minute or two.

## Adding a new project

1. Copy any file in `projects/` and rename it, e.g. `projects/ai-risk-register.md`.
2. In `index.html`, copy one `<article class="card">…</article>` block and change its text and link (`projects/ai-risk-register.html`. Note the link ends in **.html**, not .md).
3. Change a project's tag from `wip` to `done` when it's finished.
